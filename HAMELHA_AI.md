# Hamelha AI Studio

The complete new video-automation module lives in `hamelha_ai/`.

### Features
- ✍️ Text → video
- 🖼️ Images → video
- 🎬 Video → 9:16 Shorts/Reels
- 🎵 Video → MP3 engine
- ⬇️ URL → video with yt-dlp
- 🎁 Free credit system
- 🗃️ SQLite job/user storage
- 🐳 Root Dockerfile for deployment

Set `BOT_TOKEN` and `ADMIN_ID` as environment variables, then run `python -m hamelha_ai.bot`.
